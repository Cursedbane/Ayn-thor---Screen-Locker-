# Thor Lock

Свой экран блокировки для AYN Thor. Срабатывает, когда закрываешь крышку (выключается экран) дольше заданного времени (по умолчанию 1 минута).

Разблокировка на выбор:
- **Рисунок по 9 точкам** на нижнем экране, как обычная блокировка Android;
- **Комбинация кнопок геймпада** из 4–8 кнопок, как на Steam Deck.

## Как получить APK (через GitHub, без Android Studio)

1. Создай новый репозиторий на github.com (можно приватный).
2. Залей туда содержимое этой папки: `Add file → Upload files` и перетащи все файлы и папки, включая `.github`.
3. Открой вкладку **Actions**. Сборка «Build APK» запустится сама (или нажми `Run workflow`).
4. Через 3–5 минут открой готовый запуск и скачай внизу **ThorLock-apk**. Внутри zip лежит `ThorLock.apk`.
5. Закинь APK на Thor и установи (разреши установку из неизвестных источников).

APK подписан постоянным ключом (`app/release.jks`), поэтому новые версии ставятся поверх старой.

Через Android Studio: открыть папку → Build → Build APK(s).

## Первая настройка на Thor

1. Открой Thor Lock.
2. Разреши **«Поверх других окон»** (это обязательно), отключи оптимизацию батареи и разреши уведомления.
3. Выбери способ и задай рисунок или комбинацию.
4. Выбери задержку и экран для рисунка (по умолчанию нижний).
5. Включи **«Защита включена»** и проверь кнопкой «Заблокировать сейчас».

Системную блокировку Android лучше поставить на «Нет» или «Провести пальцем», иначе придётся разблокировать дважды.

## Важно знать

- Это блокировка «поверх окон», а не системная. От случайных людей и детей защищает, но это не шифрование: человек, который хорошо знает Android, может её обойти (например, через безопасный режим).
- Настройки тоже закрыты паролем.
- Забыл пароль: безопасный режим (долго держи «Перезагрузить» в меню питания) → Настройки → Приложения → Thor Lock → удалить или очистить данные.
- Если L2/R2 на Thor работают как аналоговые оси, а не кнопки, они могут не засчитываться. Тогда используй другие кнопки.
- После 5 ошибок ввод блокируется на 30 секунд, дальше дольше.
